# vcr CGI.parse on Ruby 4.0

## Dependency

vcr 6.3.1 in Gemfile.lock at the start of this pass. Gemspec asked for vcr ~> 6.3. Appraisal locks already pinned vcr 6.4.0. Development and test only. Used to load spec_helper.

## Symptom

bundle exec rspec on Ruby 4.0.2 failed before examples ran. vcr 6.3.1 calls CGI.method(:parse) at load. Ruby 3.5 and 4.0 removed CGI.parse.

## Evidence

Load error: undefined method parse for class CGI. Appraisal gemfiles already used vcr 6.4.0, which switched that call to URI.decode_www_form. Root Gemfile.lock had not followed.

## Suggested fix

Shipped in this pass: bundle update vcr --conservative on Gemfile.lock, and gemspec vcr ~> 6.3, >= 6.4.0.
